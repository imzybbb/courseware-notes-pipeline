# 课件 → 复习笔记（courseware-notes-pipeline）

> 把课堂课件（PPT，包括老式 .ppt）整理成"可以直接拿去复习"的图文笔记：公式正规排版、重点自动标出、例题原题+全过程，输出高清长图，手机滑着看。

## 它解决什么问题

- 课件里的公式大多是图片——普通工具只能提取标题级文字，"公式"一抓就瞎；
- 老式 .ppt 各种工具打不开、转出来残缺不全；
- 复习笔记的关键不在"抄"，而在**分辨什么该留、什么该重点**——多数工具只会搬运，不会提炼。

## 它特别在哪

- **逐页"看"课件**：每页导出成图片逐页核对，不依赖纯文字提取——公式、图表、细节一个不落；
- **正规数学排版**：分数、上下标、求和、积分、希腊字母都按教材样式渲染，组合数用教材式上下标写法（Cₙᵏ）；
- **会分辨重点**：按"定义/定理/公式、课件反复强调、易错点"等信号自动拣出重点，用黄色荧光高亮＋★标记＋速记卡收口；遵循来源分级（课件＞教材＞补充资料），课件有印刷错会按正确值计算并附勘误小注；
- **例题全收录**：原题原文＋计算全过程，逐题编号核对、一道不漏；
- **验收到细节**：出图后逐张复核质量，改哪页复检哪页。

## 怎么用

把课件丢给 AI，说一句「按节整理成复习笔记」即可；建议一节一节来，每节交付一批图。

## 它交付什么

- 高清长图切片（900 宽 @2x，单条消息 ≤4 张）；
- 分节 Markdown 源文档（存档、随时可重出图）；
- 课件清单＋进度表＋勘误记录（长项目不迷路）。

## 装到你的 Agent（可选）

本仓库是一个 Agent Skill：把整个目录放进你的技能目录（如 Hermes 的 `skills/`、Claude Code 的 `.claude/skills/`），Agent 读到 `SKILL.md` 就会按这套流程执行。

- 老式 .ppt 逐页导出需要 **Windows + PowerPoint**（COM 自动化，脚本在 `scripts/`）；
- 其余部分（笔记结构、公式渲染、重点标注、长图交付）与平台无关。
